FancyGrep
Section 1 : Command Description
What My Tool Does
My tool is called FancyGrep. It combines the basic ideas of the Linux grep and wc commands. The program searches a text file for a word entered by the user. It displays the lines that contain the word and also shows the total number of matching lines.
How to Run It
The program can be run in the terminal using Node.js.
Example:
node fancyGrep.js hello sample.txt
In this example, hello is the word being searched for and sample.txt is the file being searched.
Commands It Combines
My tool combines:
•	grep — searches a file for matching text.
•	wc — counts information in a file.
FancyGrep uses the idea of grep to find matching lines and the idea of wc to count how many matching lines were found.
